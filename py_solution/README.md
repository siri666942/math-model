# C题 烟幕干扰弹的投放策略 — Python求解

## 一、项目概述

本项目针对 **2026年北邮模拟赛C题《烟幕干扰弹的投放策略》** 建立数学模型并求解。该题目与 **2025年高教社杯全国大学生数学建模竞赛A题** 几乎完全一致，仅3个参数有变化。本项目将原A题的MATLAB代码重写为Python，并使用C题的新参数重新计算。

## 三、建模方法

### 3.1 运动学模型

**导弹运动**：匀速直线飞行指向假目标(原点)
```
M_dir = -M_pos0 / ||M_pos0||
M_pos(t) = M_pos0 + 300 * M_dir * t
```

**无人机运动**：等高度水平匀速直线飞行
```
FY_dir = [cos(θ), sin(θ), 0]
FY_pos(t) = FY_pos0 + v * FY_dir * t
```

**烟幕弹平抛运动**（投放→起爆）：
```
delta_t = t - t_release
smoke_pos(t) = [FY_pos_x(t), FY_pos_y(t), FY_pos_z(t) - 0.5 * g * delta_t²]
```

**烟幕云团下沉**（起爆后）：
```
smoke_pos_z(t+dt) = smoke_pos_z(t) - v_sink * dt
smoke_xy = 起爆时刻固定
```

### 3.2 遮蔽判定（核心算法）

遮蔽判据分三种情况：

1. **导弹进入云团内部**：`||M_pos - smoke_pos|| < R_eff` → **遮蔽有效**
2. **视锥遮蔽**：云团在导弹和目标之间，且目标所有关键点都在视锥内
3. **其它**：遮蔽无效

**视锥判定**：
- 以导弹为顶点，导弹→云团为中心轴，云团半径确定视锥半顶角
- 将真目标圆柱体离散为关键点集（上下底面+侧面采样点）
- 若**所有**关键点都在视锥内 → 遮蔽有效，任一关键点在视锥外 → 遮蔽无效

```
sin(α) = R_eff / ||smoke - missile||      # 视锥半顶角
cos(γ_i) = dot(axis, K_i - missile) / (|axis| * |K_i - missile|)  # 关键点i的偏离角

若 ∃i: cos(α) > cos(γ_i)  → 关键点i在视锥外 → 遮蔽无效
若 ∀i: cos(α) ≤ cos(γ_i)  → 全部在视锥内 → 遮蔽有效
```

### 3.3 优化方法

采用**两阶段搜索策略**：

**阶段1 — 快速粗筛**：
- 在几何可行区域内大规模随机采样（10000~50000点）
- 使用粗关键点(72点)和粗时间步长(0.02s)快速评估
- 滤除不可行解并保留最优候选

**阶段2 — 精确评估**：
- 对粗筛最优候选使用精细关键点(720+点)和精细步长(0.005s)精确计算
- 对问题3~5使用PSO或时序采样进行局部优化

**几何约束**（用于过滤不可行解）：
```
无人机到达时间 < 导弹到达时间
即: sqrt((x-dx)²+(y-dy)²) / v_max < (M1_x0 - x) / (300 * |cos(M1_dir)|)
```

## 七、结果分析

### 7.1 问题1遮蔽时长为0的原因

C题将投放时间从1.5s缩短为1.2s、起爆延时从3.6s缩短为3.2s，导致烟幕云团在**t=4.4s**即形成（A题为t=5.1s），比A题早0.7s。云团形成时刻导弹尚在远处（~18687m），视锥过窄无法覆盖目标。等到导弹接近云团（~9.1s），导弹已与云团x坐标持平，云团从"导弹和目标之间"变为"目标后方"，遮蔽条件不再满足。**C题参数使遮蔽窗口完全消失。**

### 7.2 问题2优于A题的原因

C题烟幕下沉速度从3.0m/s降为2.5m/s，云团在垂直方向位置更高且下降更慢，延长了导弹处于视锥内的时间。虽然无人机速度上限从140m/s降为120m/s缩小了可行域，但最优解中无人机以80m/s低速飞行即可，不受此限制。

### 7.3 问题3~5结果偏低的原因

1. **无人机速度范围收窄**（120m/s上限 vs 原140m/s）：远距离无人机（FY3在-3000m y方向）需要更高速度才能在导弹到达前飞抵有效位置
2. **FY3和FY5位于y轴负半轴**：目标在y=200，M1在y=0，这两架无人机需要跨越3200m+的y方向距离，在120m/s下几乎不可能到达
3. **问题5多导弹复杂性**：M2(y=600)和M3(y=-600)与目标M1(y=0)和目标(y=200)的几何关系各不相同，单一无人机难以同时覆盖多枚导弹
